よくある質問

チャットの履歴を非表示にすると、記録も消えますか？

消えません。「その他 → 記録 → 履歴の表示期間」では、非表示・1時間・1週間・1か月・1年・すべてから選べます。変更は次回の起動から適用されます。収支、レポート、書き出しに使う記録は残ります。「ことりのつぶやきを非表示」は、あいさつや雑談だけを隠し、記録に必要な確認やエラーは表示します。

共有中の財布の名前は変えられますか？

所有者は「その他 → 財布」から名前を変更できます。参加者は変更できません。処理が完了しなかった場合は、アプリに表示される案内に従ってください。

アカウント登録は必要ですか?

不要です。メールアドレスもパスワードもいりません。

データはどこに保存されますか?

端末内に保存されます。同期を有効にした場合のみ、あなた自身の iCloud を通じて端末間で同期されます。開発者のサーバーには送信されません。

オフラインでも使えますか?

はい。記録と学習は端末内で完結します。

家族と一緒に使えますか?

共有財布を家族やパートナーと共有できます。共有もあなた自身の iCloud だけで行われ、専用サーバーもアカウントも不要です。

他の家計簿アプリや CSV から移行できますか?

他アプリから書き出した CSV データを取り込めます。

分類を間違えたら?

一度直せば、ことりが次から覚えます(端末内で学習)。

無料で使えますか?

基本機能は無料でお使いいただけます。

前の記録を使って、新しい記録を追加できますか?

収支の記録を長押しして「コピー」を選ぶと、内容や金額、カテゴリなどが入力済みの画面が開きます。日付は今日になり、変わったところを直して「追加」で保存できます。記録画面のカードや、レポートの明細からもコピーできます。

自分が送った文章だけをコピーできますか?

記録画面で自分が送ったメッセージを長押しし、「コピー」を選びます。文章をそのままコピーでき、記録が追加されることはありません。

入力する文章は、音声入力と同じ言語で書く必要がありますか?

必要ありません。「その他 → 記録 → 音声入力の言語」は、声を文字にするための設定です。キーボードで入力する文章の言語を制限するものではありません。

操作のサウンドやバイブレーションはどこで変えられますか?

iPhoneの「設定 → アプリ → ことり」で、「サウンド」と「バイブレーション」をそれぞれ変更できます。

ショートカットで記録する財布は選べますか?

「その他 → 財布 → ショートカットの財布」で、特定の財布か「選択中の財布を使う」を選べます。特定の財布を指定しても、アプリで表示中の財布は切り替わりません。この設定は端末ごとに保存され、指定した財布を削除すると「選択中の財布を使う」に戻ります。

1日の支出通知には、どの記録が含まれますか?

すべての利用可能な財布の、今日の支出のうち、すでに発生した分が対象です。未確認の記録も含み、財布間の振替は含みません。「その他 → 通知 → 1日の支出通知」で設定額を決めると、達した日に1回お知らせします。設定から明細の確認まで、動画で見る

予算とレポートは、同じ財布を集計していますか?

レポート、グラフ、予算とその明細は、すべて「その他 → 予算管理 → 対象の財布」で選んだ範囲を集計します。新しい記録を入れる財布を切り替えても、この集計範囲は変わりません。集計範囲はレポートの上部に表示されます。「すべての財布」には今後作る財布も含まれ、個別に選んだ場合はその組み合わせを保ちます。カテゴリを非表示・削除しても、過去の支出は明細から確認できます。

予算をロックしたまま、金額を変更できますか?

はい。ロックはスライダによる変更だけを止めます。金額をタップすると、数値キーボードで編集できます。チェックマークで確認すると自動でロックされます。スライダで調整する場合は、カテゴリ名の左にあるカギのアイコンでロックを解除してください。予算設定の手順

予算の通知はどこで設定できますか?

「その他 → 通知 → 予算の通知」で、総予算・カテゴリごとの通知を選べます。「予算管理」の「予算アラート」は初期設定が80%。設定した割合に達すると事前に通知し、100%にすると事前の通知だけがオフになります。予算を超える見込みや、実際に超えたときの通知は続きます。

「超える見込み」は、すでに記録した将来の日付の支出を含む集計です。まだ記録していない買い物を予測する機能ではありません。画面上部のお知らせやiPhoneの通知をタップすると、その期間のレポートを開けます。

支出や予算のお知らせは、どこに表示されますか?

記録画面ではチャットのメッセージ、ほかの画面では上部のお知らせで確認できます。明細やレポートを開くときは、画面上部のお知らせかiPhoneの通知をタップします。チャットのメッセージからは開けません。アプリを開いていないときの通知は、各通知設定の「iOSの通知」とiPhone側の通知許可が必要です。定時の記録リマインダーも「その他 → 通知」から設定できます。

背景の色や写真、カラーオーバーレイの強さはどう変えますか？

「その他」→「カスタマイズ」の「背景」で「カラー」か「写真」を選びます。どちらも色を選べます。写真の場合、「カラーオーバーレイの強さ」は写真に重ねる色の濃さです。0%では元の写真、100%では選んだ色だけが表示されます。変化をその場で確認し、好みの見え方になったら保存してください。背景だけを元に戻すには、背景欄の「デフォルト」を選んで保存します。アクセントカラー、外観、チャットアイコンはそのままです。

チャットアイコンを写真に変えられますか?

「その他 → カスタマイズ」の下部にある「チャットアイコン」で写真を選びます。丸い表示範囲を見ながら位置と大きさを調整し、カスタマイズ画面で保存すると反映されます。同じ場所からデフォルトのアイコンに戻せます。
